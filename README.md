# REST API Development – Node.js & Express.js

This repository documents my learning journey in Backend Development, focusing on REST API development using Node.js, Express.js, and MongoDB.

The goal is to understand RESTful architecture, backend development principles, database integration, authentication, and building scalable APIs through practical implementation.

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- JSON Web Token (JWT)
- Postman
- JavaScript

## Concepts Learned

### 1. REST API Fundamentals
- Understanding REST architecture
- HTTP methods (GET, POST, PUT, PATCH, DELETE)
- HTTP status codes
- Request and response handling
- CRUD operations

### 2. Express.js
- Setting up an Express server
- Routing and controllers
- Middleware implementation
- Morgan for HTTP request logging
- Request validation
- Error handling

### 3. MongoDB & Mongoose
- Connecting Node.js with MongoDB
- MongoDB Atlas
- Creating schemas and models
- CRUD operations
- Data validation
- Database integration

### 4. Authentication & Authorization
- User registration and login
- Password handling
- JWT-based authentication
- Protected routes
- Token verification and expiration
- Forgot password functionality
- Nodemailer integration

### 5. Additional Backend Concepts
- Environment variables
- File uploads using Multer
- API testing with Postman
- RESTful API structure
- Backend application organization
