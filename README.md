# REST API Development – Node.js & Express.js

This repository documents my learning journey in Backend Development, focusing on REST API development using Node.js, Express.js, and MongoDB.

The goal is to understand RESTful architecture, backend development principles, database integration, authentication, and building scalable APIs through practical implementation.

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- JSON Web Token (JWT)
- Postman
- JavaScript
